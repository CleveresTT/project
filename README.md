# Маленький пет проект для развертывания на сервере
Этот проект прежде всего предназначен для оттачивания DevOps навыков по развертыванию сайта на удаленном сервере(с Docker или без) и по настройке CI CD.

Дополнительно попробовал Vue3, так как до этого работал коммерчески только с Vue2, попробовал наиболее часто используемые фичи.

А также попробовал Symfony на PHP8, так как до этого работал коммерчески с самописным фреймворком на основе Symfony PHP7.4, оценил удобство работы.

В папке docker_monolith оставил рабочий CI CD конфиг для развертывания без докера, а также dockerfile для сбора всего проекта в один контейнер(не развертывал на удаленном сервере).

В папке docker оставил конфиги для создания трех контейнеров, настроил для этого CI CD
